#### Sonux

[![Sonux-mikseri](https://raw.githubusercontent.com/Haxinpro/Sonux/main/docs/screenshots/sonux-mixer.png)](https://github.com/Haxinpro/Sonux)

Sonux on laitevalmistajasta riippumaton PipeWire-pohjainen äänireititin ja mikseri Linuxille. Sen tavoitteena on tehdä sovelluskohtaisesta äänireitityksestä ja äänenkäsittelystä visuaalisesti selkeämpää ja
yksinkertaisempaa käyttää.

Sonux tarjoaa Game-, Chat-, Media-, Aux- ja mukautettavat kanavat, parametrisen taajuuskorjaimen, mikrofonin käsittelyn, OBS-yhteensopivat tallennusmiksaukset sekä valinnaisen binauraalisen 7.1-tilaäänen.

Rakensin Sonuxin henkilökohtaisena oppimisprojektina SteelSeries Sonarin käyttökokemuksen inspiroimana. Projekti pohjautuu [Sink](https://github.com/NC1107/sink), jonka alkuperäinen työ muodostaa Sonuxin
perustan. Sonux ei hallitse kuulokkeiden laiteohjelmistoa tai valmistajakohtaisia toimintoja.

- Teknologiat: Rust, Tauri, React, TypeScript, PipeWire ja WirePlumber
- Lisenssi: GPL-3.0
- Testattu tällä hetkellä CachyOS-järjestelmässä

- Sivusto: [gamedexia.com](https://www.gamedexia.com/)
- Portfolio: [website-bny.pages.dev](https://website-bny.pages.dev/)

#### GameDexia

[![GameDexia homepage](https://raw.githubusercontent.com/Haxinpro/Public/main/gamedexia-homepage.png)](https://www.gamedexia.com/)

GameDexia is a public game catalog for searching and browsing games, checking release information, and filtering content.

My work has focused on the public website, search experience, media handling, performance, and deployment flow. Media is served through Bunny Storage/CDN, while Cloudflare maintains my web portfolio.

[![Sonux mixer](https://raw.githubusercontent.com/Haxinpro/Sonux/main/docs/screenshots/sonux-mixer.png)](https://github.com/Haxinpro/Sonux)

Sonux is a vendor-independent PipeWire audio router and mixer for Linux. Its goal is to make per-application audio routing and processing more visually approachable and simpler to use.

It provides Game, Chat, Media, Aux and custom channels, parametric equalization, microphone processing, OBS-compatible recording mixes, and optional binaural 7.1 spatial audio.

I built Sonux as a personal learning project inspired by the user experience of SteelSeries Sonar. It builds on [Sink](https://github.com/NC1107/sink), whose original work provides the project’s foundation.
Sonux does not manage headset firmware or vendor-specific hardware features.

- Source: [github.com/Haxinpro/Sonux](https://github.com/Haxinpro/Sonux)
- Technologies: Rust, Tauri, React, TypeScript, PipeWire, and WirePlumber
- Licence: GPL-3.0
- Currently tested on CachyOS
